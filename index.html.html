🔥 Firebase Sync

Google Firebase-এ ডেটা সেভ করুন।
কোনো লগইন ছাড়াই যেকোনো ডিভাইসে একই ডেটা পাবেন।

⚙️ একবার সেটআপ করুন
১. console.firebase.google.com যান
২. নতুন Project তৈরি করুন
৩. Realtime Database → Create Database → Start in test mode
৪. Database URL কপি করুন (যেমন: https://xxx-default-rtdb.firebaseio.com)
৫. নিচে URL বসিয়ে সেটআপ করুন

📤 Excel Export (ডাউনলোড)

আপনার সমস্ত ডেটা Excel ফাইলে সেভ করুন।
৩টি শিট থাকবে: ক্রয়, বিক্রয় ও সারসংক্ষেপ।

ফাইলের নাম: ব্যবসা_হিসাব_[তারিখ].xlsx

📥 Excel Import (আপলোড)

আগের Export করা ফাইল থেকে ডেটা ফিরিয়ে আনুন।
⚠️ নতুন ডেটা বিদ্যমান ডেটার সাথে যোগ হবে।
